03 — Méthode

Comment je travaille

Quatre étapes, toujours dans le même ordre. C'est ce qui rend une métrique défendable.

01
Cadrage

Comprendre la décision à prendre avant de toucher la donnée : quelle question, quel arbitrage, quel utilisateur.

02
Données & limites

Mesurer ce que la donnée peut réellement dire. Provenance, biais, trous : je documente les limites avant les résultats.

03
Modèle

Le modèle le plus simple qui tient. Une baseline, et une métrique choisie pour le coût réel de l'erreur — pas pour le score.

04
Décision

Livrer un outil qu'on utilise : dashboard, API ou app. Un résultat non déployé ne change aucune décision.
